# stack-using-linked-list-in-c
A menu-driven C program implementing Stack operations (Push, Pop, and Display) using a Singly Linked List.

# Stack Using Linked List in C

## Description
This program implements a Stack using a Singly Linked List in C.

## Operations
1. Push – Insert an element into the stack.
2. Pop – Delete the top element from the stack.
3. Display – Display all stack elements.
4. Exit – Exit the program.

## Concepts Used
- Structures
- Pointers
- Dynamic Memory Allocation (`malloc`)
- Memory Deallocation (`free`)
- Stack Data Structure
- Linked List

## Programming Language
C

## Data Structure
Stack using Singly Linked List
